## About Me

I enjoy turning ideas into working products, from quick mobile-first MVPs to backend-backed web platforms. My recent work explores practical full-stack systems: expense tracking, photobooth workflows, AI learning experiences, calendar scheduling, and learning/game platforms.

I like projects where product thinking and engineering meet: clear user flows, useful data models, reliable APIs, and interfaces that feel simple to use.

## What I Build

- **Mobile-first apps** with React Native, Expo, TypeScript, local storage, camera flows, notifications, and user-centered interaction patterns.
- **Web and backend platforms** with Next.js, NestJS, PostgreSQL, Prisma, REST APIs, background workers, and async processing.
- **Learning and AI tools** that help students review, generate questions, organize study flows, and follow personalized learning paths.
- **Desktop and academic systems** with Java Swing, C#, H2, client/server networking, scheduling workflows, and database-backed CRUD features.
